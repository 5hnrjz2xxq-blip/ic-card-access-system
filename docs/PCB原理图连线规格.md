## 1.3 座子脚序（按元器件资料钉死，2026-10-13 核对）

**J_RC（MFRC522 HW-126，8P 2.54 mm）** — 资料：MFRC522_引脚说明书 / HW126接线说明  
模块排针自上而下（丝印 SDA 端在上、3.3V 红线在下）：

| 序 | 模块丝印 | 网络 |
|----|----------|------|
| 1 | SDA（片选） | RC_SS（GPIO5） |
| 2 | SCK | SPI_SCK（GPIO18） |
| 3 | MOSI | SPI_MOSI（GPIO23） |
| 4 | MISO | SPI_MISO（GPIO19） |
| 5 | IRQ | **悬空不接** |
| 6 | GND | GND |
| 7 | RST | RC_RST（GPIO27） |
| 8 | 3.3V | +3V3（**仅 3.3V，禁止 5V**） |

模块 40×60 mm，工作电流 13–26 mA @3.3V，峰值 <30 mA。

**J_PN（PN532 Elechouse 模组，I2C 模式）** — 资料：PN532_模块手册_V3 / Elechouse 官方原理图  
拨码：**Channel1=ON, Channel2=OFF（I2C）**。排针按丝印顺序：

| 模块丝印 | 网络 |
|----------|------|
| VCC | +3V3（模组可 3.3–5V，本板统一 3.3V） |
| GND | GND |
| SDA | I2C_SDA（GPIO21） |
| SCL | I2C_SCL（GPIO22） |

IRQ、RSTPD_N、SIG*、INT*、DBG* 全部悬空不接。模组板载 27.12 MHz 晶振与天线，读距 5–7 cm。

**J_K1（KY-019 / CW-019 继电器模块，3P 2.54 mm）** — 资料：KY019_继电器模块资料  
脚位丝印 `+ / - / S`：

| 模块丝印 | 网络 |
|----------|------|
| + | +5V（开发板 VIN） |
| − | GND |
| S | RELAY_IN（GPIO26） |

负载侧 NO/COM **不进扩展板**：锁线直接接 CW-019 模块螺丝端子（与面包板一致，2026-10-13 定案）；板上无 J_LOCK。

> **极性定论（2026-10-13 用户确认）**：实际使用模块为 **CW-019 低电平吸合**，与 v0.3 固件一致（`digitalWrite(26, LOW)` 开门，上电初始化 HIGH）。  
> 资料包里的 KY-019（KEYES）为高电平触发版本，**不采用**；若将来换高电平模块，须把 `openDoor()` 里 RELAY 电平取反。  
> 扩展板为 3P 直通座，铜皮不受极性影响。

**J_SERVO（SG90，3P 2.54 mm）**：`+5V / GND / SIG(GPIO14)`，线序红/棕/橙。

**LS1（有源蜂鸣器模块，3P）** — 资料：蜂鸣器模块原理图（9012 + B1 + R23）：`VCC=+3V3 / GND / I/O=GPIO13`。固件高电平响。

**J_MCU（对接 ESP32-WROOM 核心板，双排 19P 母座）** — 资料：ESP32-WROOM-32原理图（CH340C 核心板，H1/H2 = PZ254-1-19）  
核心板左侧 H2、右侧 H1 自上而下脚序（与经典 DevKit 38P 一致）：

- H2：3V3, EN, SVP, SVN, IO34, IO35, IO32, IO33, IO25, **IO26**, **IO27**, **IO14**, IO12, GND, **IO13**, SD2, SD3, CMD, **+5V**
- H1：GND, **IO23**, **IO22**, TXD0, RXD0, **IO21**, GND, **IO19**, **IO18**, **IO5**, IO17, IO16, IO4, IO0, IO2, IO15, SD1, SD0, CLK

扩展板从 H1/H2 对插取电与信号：`+5V(VIN)`、`3V3`、`GND`，信号脚按 §1 表对接。

## 2. 电源架构（修订定案：仅开发板 Type-C 供电）

**无电池、无充电、无 LDO。** PCB 是 ESP32 开发板的扩展板/转接板，从开发板排针取电，分给各模块。

```
ESP32 开发板 Type-C（唯一供电入口，插 USB 时工作）
        │
   开发板 VIN ──► +5V  ──► SG90 舵机 VCC（红）
   （即 USB 5V）      └──► 继电器 CW-019 VCC
        │
   开发板 3V3 ─► +3V3 ──► MFRC522（仅 3.3 V）
   （板载 LDO）      ├─► PN532 模组（3.3 V）
        │            ├─► OLED SSD1306（3.3 V）
        │            ├─► 有源蜂鸣器模块（3.3 V）
        │            └─► I2C 上拉 4.7 kΩ
        │
   开发板 GND ──► GND（全板共地，含舵机/继电器模块 GND）
```

要点：

1. **唯一供电路径**：开发板 Type-C。扩展板上不接电池、不装 TP4056/AMS1117/DW01/FS8205A。
2. **+5 V** 取自开发板 **VIN** 脚（与 Type-C VBUS 同轨），只供舵机 + 继电器 CW-019。
3. **+3 V3** 取自开发板 **3V3** 脚（开发板板载 LDO 输出），供读卡/显示/蜂鸣器/逻辑。
4. **共地**：扩展板 GND 网络必须与开发板 GND 单点可靠连接；舵机、继电器模块 GND 一并回这里。
5. 舵机堵转峰值电流可达安培级，**+5 V 入口就近放 ≥100 µF 电解 + 100 nF 陶瓷**，防止 USB 掉压复位。
6. 不在扩展板上做 5 V/3.3 V 转换；两轨不得短接。
7. 烧录/日志：直接用开发板 Type-C（板载 USB-UART），扩展板不设下载电路。

## 3. 继电器 CW-019（低电平触发）

| CW-019 脚 | 接到 | 说明 |
|-----------|------|------|
| VCC | **+5 V（开发板 VIN）** | 线圈 5 V，模块自带驱动 |
| GND | GND | |
| IN | **GPIO26** | **LOW = 吸合**，HIGH = 释放 |

固件行为（必须与此一致）：

- 上电初始化：`digitalWrite(RELAY_PIN, HIGH)` → 默认释放（关门）。
- 开门：`digitalWrite(RELAY_PIN, LOW)` → 吸合 3 秒 → `HIGH` 释放。

PCB 落地：**板上 3P 排针座（VCC/GND/IN），直插现用 CW-019 模块**——与面包板实验一致，零改固件，不做分立驱动电路。

模拟锁/负载：直接接继电器模块螺丝端子 NO/COM（不经扩展板）。

## 5. 读卡（双读卡器）

### 5.1 MFRC522（SPI，实体 Mifare / Classic）

| 模块脚 | GPIO | 网络 |
|--------|------|------|
| SCK | 18 | SPI_SCK |
| MISO | 19 | SPI_MISO |
| MOSI | 23 | SPI_MOSI |
| SDA（片选） | 5 | RC_SS |
| RST | **27** | RC_RST |
| 3.3V | 3V3 | 仅 3.3 V 供电，禁止 5 V |
| GND | GND | |

- 只能 3.3 V 供电（模块丝印明确标注）。
- 若板载 QFN 裸片：必须补 **Y1 27.12 MHz 晶振 + 负载电容**，天线匹配按 NXP AN1444/AN1445 实测；天线区净空、禁止铺铜。
- 若沿用现成 MFRC522 模组：保留 SPI 接线，天线在模组上，板上只留接口。

### 5.2 PN532（I2C，手机 HCE + Ntag215 密钥读写）

| 模块脚 | GPIO | 网络 |
|--------|------|------|
| SDA | 21 | I2C_SDA |
| SCL | 22 | I2C_SCL |
| 3V3 | 3V3 | |
| GND | GND | |

- **拨码开关：1→ON，2→OFF（I2C 模式）**，丝印注明。
- IRQ、RST **悬空不接**（固件为 -1）。
- 与 OLED 共享 I2C 总线；OLED 地址 0x3C。
- 固件逻辑：522 优先快检；Classic 只验 UID；Ntag215（7 字节 UID）转交 532 做 UID+卡内密钥双重验证，因此 532 不可省略。
- 模组天线朝外/朝刷卡区，板边放置。

### 5.3 I2C 总线

- SDA=21、SCL=22，上拉 4.7 kΩ 到 +3V3（模组自带上拉可省，二选一勿重复）。
- 走线尽量短，远离天线区。

## 7. 人机与管理（无 LED、无按键）

- OLED SSD1306 128×64 I2C（0.96"）：VCC/GND/SDA/SCL = 3V3/GND/21/22。
- 管理卡 UID `5B 50 E7 53`：碰一下=添加模式；按住 ≥3 s=删除模式；超时 5 s 自动退出。
- WiFi 热点：SSID `门禁管理` / 密码 `12345678`，Web 管理页 `http://192.168.4.1`（增删卡、刷卡录入、清空恢复默认）。
- 串口命令：`LIST`、`CLEAR`（115200）。
- 白名单默认两条：`3320F505`、`D30C8B8E`；Ntag215 密钥 16 字节写 Page 4–7。

## 9. PCB 布局注意

1. 天线净空：MFRC522 模组、PN532 模组天线区禁止铺铜/走线；开发板天线朝外悬空，扩展板元件让开该区域。
2. +5 V 走线加宽（舵机峰值电流），与 +3 V3 逻辑分区。
3. I2C 短走线，远离天线与 +5 V 开关节点。
4. 扩展板以排针/排母对接开发板；J_SERVO、J_K1、各模组座分区清晰，丝印标注。
5. 四角 M3 安装孔保留。
