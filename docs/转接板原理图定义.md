# 转接板原理图定义（v0.3 · 2026-10-13）

板名：IC卡门禁-转接板  
类型：ESP32 核心板扩展板（纯连接，无源器件仅上拉/去耦）  
依据：docs/PCB原理图连线规格.md §1.2/§1.3

| 位号 | 符号/器件 | 引脚数 | 封装（PCB 用） |
|------|-----------|--------|----------------|

| J_RC | Header 1×8 2.54 | 8 | 8P 单排母（MFRC522 HW-126） |
| J_PN | Header 1×4 2.54 | 4 | 4P 单排母（PN532） |

| J_BZ | Header 1×3 2.54 | 3 | 3P 单排母（蜂鸣器） |
| R1 | 4.7kΩ | 2 | 0603（I2C SDA 上拉） |

## 2. 网络表（net → 连接）

### 电源

| 网络 | 来源 | 负载 |
|------|------|------|
| +5V | J_MCU 对应脚（H2-19 VIN/+5V） | J_RC 无、J_K1-1(+)、J_SERVO-1(VCC)、C1+、C2 |
| +3V3 | J_MCU 对应脚（H2-1 3V3） | J_RC-8、J_PN-1、J_OLED-1、J_BZ-1、R1-1、R2-1、C3、C4 |
| GND | J_MCU GND 脚（H1-1/H1-7/H2-14） | 所有座子 GND 脚、C1-、C2、C3、C4 |

### 信号（1:1 = 面包板接线图）

| 网络 | 起点 | 终点 |
|------|------|------|
| RC_SS | J_MCU IO5 | J_RC-1 (SDA) |
| SPI_SCK | J_MCU IO18 | J_RC-2 (SCK) |
| SPI_MOSI | J_MCU IO23 | J_RC-3 (MOSI) |
| SPI_MISO | J_MCU IO19 | J_RC-4 (MISO) |
| （悬空） | J_RC-5 (IRQ) | 不接 |
| RC_RST | J_MCU IO27 | J_RC-7 (RST) |
| I2C_SDA | J_MCU IO21 | J_PN-3 (SDA)、J_OLED-3 (SDA)、R1-2 |
| I2C_SCL | J_MCU IO22 | J_PN-4 (SCL)、J_OLED-4 (SCL)、R2-2 |
| RELAY_IN | J_MCU IO26 | J_K1-3 (S) |
| （锁负载） | 不进板 | CW-019 模块螺丝 NO/COM 直接接锁 |
| SERVO_SIG | J_MCU IO14 | J_SERVO-3 (SIG) |
| BUZZER_IO | J_MCU IO13 | J_BZ-3 (I/O) |

注：J_K1 只有 3P 控制侧（+/−/S）。NO/COM 在模块螺丝端子上，锁线直接接模块，不经扩展板（2026-10-13 定案）。

## 3. 座子脚序（符号引脚从上到下 = 模块丝印从上到下）

### J_MCU（对接核心板，只引出用到的脚）
按 H1/H2 物理序建两个 1×19 符号或一个 2×19：
- **H2**（1..19）：3V3, EN, SVP, SVN, IO34, IO35, IO32, IO33, IO25, IO26, IO27, IO14, IO12, GND, IO13, SD2, SD3, CMD, +5V
- **H1**（1..19）：GND, IO23, IO22, TXD0, RXD0, IO21, GND, IO19, IO18, IO5, IO17, IO16, IO4, IO0, IO2, IO15, SD1, SD0, CLK

本板实际只布线用到：H2-1(3V3)、H2-10(IO26)、H2-11(IO27)、H2-12(IO14)、H2-14(GND)、H2-15(IO13)、H2-19(+5V)；H1-1(GND)、H1-2(IO23)、H1-3(IO22)、H1-5(IO21)、H1-7(GND)、H1-8(IO19)、H1-9(IO18)、H1-10(IO5)。其余脚在符号上保留但悬空（便于以后扩展，也保证对插不歪脚）。

### J_RC（MFRC522 HW-126，8P）
1 SDA(RC_SS)、2 SCK、3 MOSI、4 MISO、5 IRQ(空)、6 GND、7 RST、8 3V3

### J_PN（PN532，4P）
1 VCC、2 GND、3 SDA、4 SCL

### J_K1（CW-019，3P 控制侧）
1 +、2 −、3 S

### J_SERVO（SG90，3P）
1 VCC、2 GND、3 SIG

### J_OLED（4P）
1 VCC、2 GND、3 SDA、4 SCL

### J_BZ（蜂鸣器，3P）
1 VCC、2 GND、3 I/O

## 4. 布局草图（原理图一页）

```
        +5V ─────────────────────────────────┬────────── J_K1 +
        │                                    └────────── J_SERVO VCC
        C1+ C2
        │
  +3V3 ─┼── R1 ── I2C_SDA ──┬── J_PN SDA
        ├── R2 ── I2C_SCL ──┼── J_PN SCL
        ├── J_RC 8(3V3)      ├── J_OLED SDA/SCL
        ├── J_PN 1           └── (R1/R2 另一端 → +3V3)
        ├── J_OLED 1
        ├── J_BZ 1
        └── C3 C4

  GND ── 所有座子 GND + C1- C2 C3 C4

  J_MCU ── RC_SS/SPI_*/RC_RST/I2C_*/RELAY_IN/SERVO_SIG/BUZZER_IO ── 各座子信号脚
```

## 5. 绘制顺序（EDA API）

1. 建工程 `IC卡门禁-转接板`
2. 放 7 个 Header + R1/R2 + C1–C4
3. 按 §3 脚序打网络标号（net label），电源用电源符号
4. 检查 ERC（无悬空必须脚：仅 J_RC-5 IRQ 与 J_MCU 未用脚可悬空）
5. 保存，然后进 PCB
