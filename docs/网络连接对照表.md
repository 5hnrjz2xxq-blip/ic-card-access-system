## 六、EDA 操作步骤

### 步骤1：添加电源符号
1. 点击工具栏 **VCC** 按钮（或快捷键）
2. 在需要+3V3的引脚上放置，修改网络名为 `+3V3`
3. 同理放置 `+5V` 和 `GND` 符号
4. 电源符号位置：
   - +5V: J1-19, J6-1, J7-1, C1+, C2
   - +3V3: J1-1, J3-8, J4-1, J5-1, J8-1, R1-1, R2-1, C3, C4
   - GND: 所有GND引脚

### 步骤2：添加网络标签
1. 按快捷键 **Alt+N** 激活网络标签工具
2. 在每个信号引脚上点击
3. 输入对应的网络名（如 `RC_SS`、`SPI_SCK` 等）
4. 信号引脚列表见上方"信号网络汇总"

### 步骤3：检查 ERC
1. 菜单 → 设计 → ERC检查
2. 确认无错误
3. 保存工程
