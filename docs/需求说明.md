# IC 卡门禁系统 · 需求说明（方案 A 定案）

课程：数字信号处理 · 电子系统设计实训  
状态：方案 A 已定稿（2026）

## 1. 产品定位

门边**旁置演示作品**：不改动家里原有机械锁；继电器带小负载/LED 模拟开门。  
供电：充电宝或内置锂电池（板载充放电）。  
验收以 **基础 + 提高档** 为主，网络开锁为加分项。

## 2. 主控与工具链

| 项 | 定案 |
|----|------|
| 主控 | **ESP32-WROOM-32E**（或 ESP32-S3 模组）自制板 |
| WiFi / BLE | 模组自带 |
| HomeKit | **软件 HAP**（如 HomeSpan 等），非 MFi 认证成品 |
| 开发 | VS Code + PlatformIO（与现有仓库一致） |
| 烧录/调试 | **macOS 可用**：USB 串口 `esptool` / `pio run -t upload`；串口监视 `pio device monitor` |
| 不用作本体 | 正点原子 ATK-T5（涂鸦生态，无原生 HomeKit 主路径） |

### 为何不用 ATK-T5 做 HomeKit 主控

T5 官方路径是涂鸦 / Google Home / Alexa；原生 Home 配件与软件 HAP 生态在 ESP32 上更成熟。ATK-T5 可留作对照，不进本板 BOM 主控位。

## 3. 功能需求

### 3.1 基础档（必须）

| ID | 需求 | 说明 |
|----|------|------|
| F1 | 读 IC 卡 UID | MFRC522 + Mifare S50/CUID |
| F2 | 白名单鉴权 | 命中开门；未命中拒绝 |
| F3 | 错误卡报警 | 蜂鸣器短鸣 + 红 LED |
| F4 | 开门指示 | 绿 LED + 继电器吸合可配时间 |
| F5 | 本地提示 | OLED 显示卡号 / 通过 / 拒绝 / 网络状态 |

### 3.2 提高档（必须）

| ID | 需求 | 说明 |
|----|------|------|
| F6 | 管理员增删卡 | 按键或配对流程进入管理态；卡表可改 |
| F7 | 进出记录 | 保留最近 N 条（时间戳 + UID + 结果） |
| F8 | 掉电保存 | 白名单与记录存 NVS/Flash |
| F9 | 防重读 | 同卡冷却时间（如 2–3s），滤波说明写入报告 |

### 3.3 网络与开锁通道（方案 A 定稿）

| ID | 通道 | 平台 | 行为 |
|----|------|------|------|
| F10 | **Home App 软件开锁** | iPhone / iPad | 家庭 App 中的软件 HomeKit「门锁」，点按锁/开 |
| F11 | **NFC → 快捷指令** | iPhone | 碰墙贴 NFC 标签 → 快捷指令自动化 → 联网开锁 |
| F12 | **NFC 当卡直接刷开** | 安卓 / 鸿蒙 | **手机模拟 IC 卡**，板载读头 **直接读到手机** 后鉴权开锁；**不是**碰墙贴触发网络命令 |
| F13 | BLE 辅助（可选） | 任意 | 近场补充，非本课设必须 |

**F12 实现约束（必须写进报告）：**

- 「像刷 IC 卡一样刷手机」= 读头读 **手机卡模拟（HCE）**，不是读墙贴。
- 系统无「任意第三方读头可读的空口虚拟卡」开放能力时，安卓/鸿蒙需 **极简 HCE 虚拟卡小程序/助动**（只呈现一张可被本板识别的卡，**不做完整门禁业务 App**）。
- 读头需同时照顾：实体 Mifare 卡 + 手机 HCE（ISO-DEP）。**MFRC522 对手机 HCE 不友好**；手机当卡优先 **PN532**（可与 MFRC522 并存：课设实体卡 / 手机卡）。
- **iPhone 仍走 F10 + F11**，不做原生 Home Key（MFi 超范围）。

## 4. 硬件与安装边界

- **旁置**，继电器干接点/小功率负载模拟，**不接入**原锁芯动力。
- 天线：MFRC522 天线区净空；WiFi 天线按模组手册 keep-out。
- 结构：门边固定，充电口可触达；电池仓与强电隔离。

## 5. 明确不做 / 超范围

- 不做联网门禁云平台、人脸、远程大盘后台  
- 不做 MFi / Home Key 认证与仿制  
- 不做 12V 真锁联动（可预留光耦/继电器接口扩展）  
- 不做量产安规认证  

## 6. 验收分级

1. **基础**：读 UID、白名单开门、错误报警  
2. **提高**：管理员增删卡、进出记录、掉电保持  
3. **加分**：Home App 开锁；iPhone 碰墙贴快捷指令；**安卓/鸿蒙手机当卡被读头直接刷开**  

## 6.1 答辩演示脚本（两遍开锁）

**第一遍：实体 IC 卡**

1. 白卡靠近 **MFRC522** 读头（3–5 cm）
2. ESP32 读到 UID → 查白名单 → 命中
3. OLED 显示「已通过」；绿 LED 亮；蜂鸣器短鸣
4. 继电器通电 → **电控锁舌缩回**（可听到咔哒声）→ 「门开」
5. 3 秒后继电器断电 → 弹簧复位 → 锁舌弹出 → 「门锁上」

**第二遍：安卓手机当卡**

1. 手机打开 HCE 虚拟卡（后台保持）
2. 手机靠近 **PN532** 读头（同一外壳上）
3. ESP32 读到虚拟卡 ID → 查白名单 → 命中
4. 同上：OLED / 绿 LED / 蜂鸣器 / **锁舌缩回 → 3 秒后弹出**

两路走同一套白名单鉴权逻辑，老师看到的是同一个物理锁舌动作。

**白名单需存两条：**

| 条目 | 来源 | 值 |
|------|------|-----|
| UID_1 | 实体白卡（上板后先读出） | 如 `A3 B2 C1 D0` |
| UID_2 | 手机 HCE 虚拟卡（App 内设定） | 如 `04 11 22 33` |

**macOS 全链开发（无需 Windows）：**

| 环节 | 工具 |
|------|------|
| 编译 / 烧录 / 监视 | PlatformIO + CH340C 驱动（WCH 官方 Mac 版） |
| HomeKit | HomeSpan 库（Arduino framework） |
| MFRC522 | miguelbalboa/MFRC522 |
| PN532 | Adafruit PN532 |
| 安卓 HCE 虚拟卡 App | Android Studio（Mac 版） |
